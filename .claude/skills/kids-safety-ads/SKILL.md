# Kids Safety, Ads & Monetisation Compliance

## Procedure
1. Ask the developer to confirm intended target age groups and markets.
2. Review current Google Play Families, User Data, Ads, Payments and target-audience policies.
3. If children or unknown-age users may see ads, verify the exact SDK version against the current Families self-certified list.
4. Implement neutral age screening if the app targets both children and older users and policy requires it.
5. Ensure ads are optional, age-appropriate and never interrupt active gameplay.
6. Review analytics, identifiers, consent, retention, privacy policy and data safety declarations.
7. Review purchases, parental controls, restore purchases and refund flows.
8. Recheck policies and SDK status immediately before release.

## Rules
- No paid loot boxes or simulated gambling.
- No forced mid-run ads.
- No manipulative countdowns or false scarcity.
- Never assume an SDK is compliant because its brand is familiar.
- This skill is not legal advice; escalate uncertain jurisdictional issues.

## Checklist
- [ ] Target audience confirmed.
- [ ] Current policy checked.
- [ ] SDK version verified.
- [ ] Data collection minimized.
- [ ] Ads optional and age-appropriate.
- [ ] IAP disclosures and restore flow tested.
