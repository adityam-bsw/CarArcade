Per-wheel anchors (canvas px from top-left, world units vs body centre, radius, PNG size) are in `wheels_v4.json` beside this file (schema: id -> canvasW, canvasH, S, widthUnits, changed, wheels[cx, cy, r, size, worldX, worldY, worldR]); wheel wells in the bodies are dark discs centred on those anchors. Unchanged vehicles keep their old anchors (from the old table above). Generator: tools/art/vehicle_layout.py + make_vehicles2.py. Game code still uses the old anchors until the implementer applies wheels_v4.json.
