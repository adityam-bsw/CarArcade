# Progression and economy (blueprint section D) - current logic

Code: `Assets/Scripts/Game/Progression/`. Tests: `Assets/Tests/EditMode/ProgressionTests.cs`. Spec: `Docs/design/BLUEPRINT_C_D.md` section D, `Docs/design/economy.md` section 15.

- **Data (ScriptableObjects, loaded from `Resources/Progression/`, code defaults when the asset is absent):** `UpgradeTreeSO` (costs 500/900/1500/2500/4000, +6% of the base per level, base per branch, per-vehicle overrides), `WorldGateSO`, `VehicleGateSO`, `ProgressionTuningSO` (scrap, mastery table, goal stubs, daily, weekly stub, ad limits, first-hour schedule). No assets are created yet: defaults are used until a builder or the Create menu makes them.
- **Upgrades:** levels owned are 0..5 per branch (Engine, Suspension, Ink, Boost, Shield) per vehicle key (`PlayerProfile.upgrades`). Bonus = base x 6% x level: engine 11.5 m/s -> +0.69 per level (was 0.8), suspension torque 34 -> +2.04 (was 3), ink 100 -> +6 (was 30), boost +0.08 s via `GameplayTuning.boostDurationPerLevel`. Shield is data only (no garage row, no gameplay effect). Garage still shows four rows. Per-vehicle boost overrides are not read by `RunDirector` (it uses the tuning field).
- **Save version 2:** old global levels (1..5) become 0..4 for any vehicle without an entry (lazy, in `UpgradesFor`). `Sanitize` migrates v1: lifetime distance = best distance, desert and night-city worlds and the selected world stay unlocked. Owned vehicles/worlds are never re-gated.
- **Scrap:** `profile.scrap`, awarded on a boss defeat (20 first / 10 repeat); `GameModel.Scrap` mirrors it; no UI yet.
- **Mastery:** per-vehicle lifetime metres, levels 500/2000/5000/10000/20000, coins and gems paid to the profile once (mask), sticker/colour/cosmetic recorded in the mask only. Recorded at run end in `RoadGameManager.TriggerGameOver`. The older xp mastery in `MetaProgress` is untouched.
- **Gates:** `GateService` checks lifetime distance and an extra counter (`gate:<ExtraGate>` in `profile.counters`, nothing increments these yet). Not wired to the world/vehicle selection UI.
- **Daily:** `DailyChallenge` seed = FNV-1a of the UTC `yyyyMMdd`; vehicle, world, three events (from `dailyEventIds`, not yet matrix filtered) and 100-250 coins from `Pcg32`. Local best, one claim per UTC day (coins, 1 mastery point, 1 weekly token). Weekly is a key plus a token counter only. No UI.
- **Ads:** `IAdService` with `NoOpAdService` (release) and `EditorFakeAdService` (editor/dev builds). `AdOffers`: 2x coins 2/day, extra daily reward 1/day, revive 1 per run, never while a run is active, counters in the profile, spent only on a rewarded result. Not wired into any screen. No SDK.
- **First hour:** `ProgressionTuningSO.firstHour` and `FirstHour.Claim`; data only.
